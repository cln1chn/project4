quiet interaction portfolio starter

folder structure:
index.html
projects.html
about.html
contact.html
css/style.css
js/script.js
img/

what to replace:
1. replace "your logo" with your logo image in each html file.
2. add your project images inside the img folder.
3. update each project-card on projects.html:
   - data-title
   - data-image
   - data-alt
   - data-description
4. replace about-photo.jpg with your own photo.
5. replace about/contact text with your own writing.
6. connect the contact form to a real service if your professor requires actual submission.

color palette:
background: #f4f1ec
surface: #ebe6df
text: #24211f
muted: #8a8178
accent: #ff4f21

design notes:
all text is lowercase by default using css text-transform.
the navigation uses four fixed positions on desktop:
home top, projects left, about right, contact bottom.
on mobile, the nav becomes a simple horizontal menu so the site remains usable.
